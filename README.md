О проекте

PAYVU_KR - консольное приложение на C++ для учёта экземпляров книг. Программа хранит сведения о книгах в хеш-таблице, позволяет выполнять операции с записями и сохранять данные в текстовые файлы.

У каждого экземпляра книги есть:
- уникальный инвентарный номер (ID);
- название (title);
- автор (author);
- год издания (yearOfRelease) - целое число от 1700 до 2026 включительно.
- текущий статус (curState): GIVEN - выдана, INSTOCK - на складе.


Функциональные возможности программы

В главном меню доступны:

1. Добавление нового экземпляра книги.
2. Редактирование автора, названия и года издания.
3. Удаление книги по инвентарному номеру.
4. Поиск по инвентарному номеру, автору или названию.
5. Изменение статуса книги.
6. Вывод всех книг.
7. Вывод книг, находящихся на складе.
8. Вывод выданных книг.
9. Загрузка данных из текстового файла.
10. Сохранение данных в текстовый файл.
11. Справка о работе приложения.
12. Дополнительные функции: число занятых ячеек хеш-таблицы и максимальная длина цепочки.

При первом запуске программа запрашивает размер хеш-таблицы. 
Для отмены выбранных действий используется латинская буква e.

Архитектура

Программа разделена на три функциональные части:

1. Данные и алгоритмы (dataStructures.*) - экземпляры книг и их хранение в хеш-таблице.
2. Текстовый интерфейс (menuFunctions.*) - ввод команд, меню и вызов операций.
3. Вспомогательные функции (utils.*) - подготовка ввода и обработка ошибок.


Хеширование и обработка коллизий

Для размещения экземпляров книг в таблице используется собственная функция bookTable::hash(string bookID). Её реализация в исходном коде:

unsigned int bookTable::hash(string bookID) {
    unsigned res = 0;
    for(char c : bookID) {
        res = (res+1) * c + 15;
    }
    return res;
}

Коллизии разрешаются методом цепочек.


Сборка в Qt Creator

1. Убедитесь, что все файлы находятся в директории согласно структуре проекта, описанной выше
2. Запустить Qt Creator.
3. Выбрать папку проекта и открыть CMakeLists.txt.
4. При конфигурации проекта выбрать компилятор LLVM-MinGW.
5. Выбрать конфигурацию Debug или Release.
6. Выполнить сборку проекта с помощью кнопки Build
7. Файл test.txt поместить в одну директорию с исполняемым файлом в соответствующей папке.
8. Запустить приложение.

Первый запуск

1. Запустить приложение.
2. Ввести положительный размер хеш-таблицы (например 10).
3. Выбрать действие из главного меню.
4. Для добавления книги ввести инвентарный номер, название, автора, год и статус.
5. При необходимости сохранить текущие данные через пункт 10.
6. Для последующей загрузки данных использовать пункт 9.
